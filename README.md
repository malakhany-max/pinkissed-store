Pinkissed Store 🎀
Simple full-stack e-commerce website for handmade pins.

✨ Features:
Product listing & details
Shopping cart
Cash on delivery orders
User login & register
Admin dashboard (manage products & orders)
Order history

🧱 Tech Stack:
Node.js + Express
SQLite
JWT Authentication
HTML / CSS / JavaScript
🚀 Run Locally
npm install
npm run dev

Open:
http://localhost:3000
🔐 Notes:
Role-based access (User / Admin)
Secure API with authentication & validation
Protected admin routes
