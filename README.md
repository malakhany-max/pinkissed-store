# 🎀 Pinkissed Store

A full-stack e-commerce website for handmade pins. Users can browse products, manage their carts, place orders, and manage their accounts with a secure authentication system.

## 🔗 Live Demo
  https://malakhany-max.github.io/pinkissed-store/

## 💻 Repository
https://github.com/malakhany-max/pinkissed-store

## ✨ Features

- User registration and login system.
- User authentication and account management.
- Product listing with product details.
- Shopping cart management.
- Add, remove, and update cart items.
- Calculate total order price.
- Cash on delivery orders.
- View user order history.
- Admin dashboard for managing products and orders.
- Add, edit, and delete products as an admin.
- Role-based access for Users and Admins.
- Protected admin routes.
- Responsive design.

## 🧱 Tech Stack

- Node.js
- Express.js
- SQLite
- JWT Authentication
- HTML5
- CSS3
- JavaScript

## 🔐 Security

- JWT-based authentication.
- Role-based authorization.
- Protected API routes.
- Input validation.
